# Dataset attribution and license

This repository includes `fraud.csv.zip`. Inside it is `fraud.csv`, an unmodified-content copy of the BankSim file `bs140513_032310.csv`. The filename was changed so the notebook can use a short, readable relative path, and the file was compressed for distribution through GitHub.

## Source

- **Dataset:** [Synthetic data from a financial payment system](https://www.kaggle.com/datasets/ealaxi/banksim1)
- **Creator:** Edgar Alonso Lopez-Rojas
- **License:** [Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/) (CC BY-NC-SA 4.0)

The dataset is synthetic and was generated by the BankSim payment simulator for fraud-detection research. It does not contain real personal or private banking transactions.

## Citation

Lopez-Rojas, E. A., & Axelsson, S. (2014). *BankSim: A bank payments simulator for fraud detection research*. Proceedings of the 26th European Modeling and Simulation Symposium, 144–152.

## Changes

The CSV contents are unchanged. The filename was changed from `bs140513_032310.csv` to `fraud.csv`, and that file was placed in a ZIP archive for use in this project.

The dataset license applies to the included dataset. No separate license is asserted here for the notebook code.
